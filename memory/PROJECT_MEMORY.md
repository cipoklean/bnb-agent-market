# PROJECT MEMORY — BNB Agent Market Core

## Vision
A marketplace layer for discovering, hiring, paying, monitoring, and revoking AI agents on BNB Smart Chain — not a landing page, not a portfolio: a full operating layer for agents.

## Products
1. **AlphaDesk** — DeFi & Trading agent marketplace (PancakeSwap automation: LP rebalancing, yield harvesting, safe swaps).
2. **TaskChain Bazaar** — Productivity & Automation agent marketplace (DAO voting, airdrop claims, monitoring, reporting, subscriptions).

## Core Goals
- Users discover agents registered under ERC-8004 (agent identity).
- Users verify identity + track record before hiring.
- Users hire safely: session manifests, spending limits, permissions, expiries, revocation.
- Users pay with Binance x402.
- Every action produces proof (tx hash, memory hash, receipt, attestation, log).
- Memory-first: no agent or sub-agent acts without a confirmed, hash-verified session manifest.

## Hackathon Alignment (BNB Agent Studio marketplace challenge)
- ERC-8004 identity and track record.
- Binance x402 payments.
- Altana session limits (spend caps, expiry, revocation).
- PancakeSwap DeFi utility (AlphaDesk).
- TermiX agent advantage reporting.
- AltLayer observability (placeholder panel if unavailable).

## Current Priority
Phase 0 (memory foundation) → Phase 1-2 (design system + marketplace core) → Phase 3-4 (verticals) → Phase 5-6 (memory/confirm centers + evidence). Full working demo over depth in any single area.
